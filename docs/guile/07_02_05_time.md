#### 7.2.5 時間 [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#Time-1)

Scheme Procedure: **current-time** [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-current_002dtime)

C 関数: **scm\_current\_time** () [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-scm_005fcurrent_005ftime)

1970年1月1日00:00:00 UTCからの秒数を返します。うるう秒は除きます。

スキーム手順: **gettimeofday** [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-gettimeofday)

C 関数: **scm\_gettimeofday** () [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-scm_005fgettimeofday)

1970年1月1日00:00:00 UTCからの秒数とマイクロ秒数（閏秒を除く）のペアを返します。注：マイクロ秒単位の精度が利用できるかどうかは、オペレーティングシステムによって異なります。

以下の手順は、分解された時間を表すオブジェクトを受け取り、選択されたコンポーネントを返すか、分解された時間を表すオブジェクトと値を受け取り、コンポーネントをその値に設定します。括弧内の数字は、通常の範囲を示します。

スキーム手順: **tm:sec** tm [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-tm_003asec)

スキーム手順: **set-tm:sec** tm val [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-set_002dtm_003asec)

秒（0～59）。

スキーム手順: **tm:min** tm [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-tm_003amin)

Scheme Procedure: **set-tm:min** tm val [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-set_002dtm_003amin)

分（0～59分）。

スキーム手順: **tm:hour** tm [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-tm_003ahour)

スキーム手順: **set-tm:hour** tm val [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-set_002dtm_003ahour)

営業時間（0～23時間）。

スキーム手順: **tm:mday** tm [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-tm_003amday)

スキーム手順: **set-tm:mday** tm val [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-set_002dtm_003amday)

月の日付（1～31日）。

スキーム手順: **tm:mon** tm [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-tm_003amon)

Scheme Procedure: **set-tm:mon** tm val [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-set_002dtm_003amon)

月齢（0～11ヶ月）。

スキーム手順: **tm:year** tm [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-tm_003ayear)

スキーム手順: **set-tm:year** tm val [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-set_002dtm_003ayear)

（70-）は、1900年を引いた年です。

スキーム手順: **tm:wday** tm [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-tm_003awday)

Scheme Procedure: **set-tm:wday** tm val [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-set_002dtm_003awday)

曜日（0～6）で、日曜日は0で表されます。

スキーム手順: **tm:yday** tm [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-tm_003ayday)

スキーム手順: **set-tm:yday** tm val [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-set_002dtm_003ayday)

年間通算日数（0～364日、閏年は365日）。

スキーム手順: **tm:isdst** tm [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-tm_003aisdst)

Scheme Procedure: **set-tm:isdst** tm val [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-set_002dtm_003aisdst)

夏時間表示（0は「いいえ」、0より大きい場合は「はい」、0より小さい場合は「不明」）。

スキーム手順: **tm:gmtoff** tm [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-tm_003agmtoff)

スキーム手順: **set-tm:gmtoff** tm val [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-set_002dtm_003agmtoff)

UTCからの西方向のタイムゾーンオフセット（秒）（-46800～43200）。例えば、米国東海岸（タイムゾーン「EST+5」）では、冬期は18000（つまり_5\*60\*60_）、夏時間中は14400（つまり_4\*60\*60_）となります。

`tm:gmtoff` は、C言語の `tm` 構造体における `tm_gmtoff` とは異なります。`tm_gmtoff` は東経秒数を表すため、ここでの値の負の値となります。

スキーム手順: **tm:zone** tm [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-tm_003azone)

スキーム手順: **set-tm:zone** tm val [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-set_002dtm_003azone)

タイムゾーンラベル（文字列）。必ずしも一意である必要はありません。

  

スキーム手順: **localtime** 時刻 \[zone\] [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-localtime)

C 関数: **scm\_localtime** (time, zone) [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-scm_005flocaltime)

時間の構成要素を分解したオブジェクト（`current-time` が返すような整数）を返します。計算に使用するタイムゾーンは、オプションで zone（文字列）で指定できます。指定しない場合は、環境変数 `TZ` またはシステムのデフォルト値が使用されます。

スキーム手順: **gmtime** 時間 [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-gmtime)

C 関数: **scm\_gmtime** (time) [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-scm_005fgmtime)

時間の構成要素を分解した値を表すオブジェクト（`current-time`が返すような整数）を返します。値はUTCで計算されます。

スキーム手順: **mktime** sbd-time \[zone\] [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-mktime)

C 関数: **scm\_mktime** (sbd\_time, zone) [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-scm_005fmktime)

分解された時間オブジェクト sbd-time に対して、`car` が `current-time` のような整数時間であり、`cdr` が正規化されたフィールドを持つ新しい分解された時間であるペアを返します。

zone はタイムゾーン文字列です。デフォルト値は `TZ` 環境変数またはシステムデフォルト値です (GNU C ライブラリ リファレンス マニュアルの [`TZ` を使用したタイムゾーンの指定](https://doc.guix.gnu.org/libc/latest/en/libc.html#TZ-Variable) を参照)。sbd-time はそのタイムゾーンにあるものとみなされます。

sbd-time では、`tm:year`、`tm:mon`、`tm:mday`、`tm:hour`、`tm:min`、`tm:sec`、`tm:isdst` の各フィールドが使用されます。これらの値は、通常の範囲外の値をとることができます。例えば、`tm:hour` は通常 23 までですが、例えば 33 という値は、翌日の 9 を意味します。

sbd-time の `tm:isdst` は、指定された時刻が夏時間適用時かどうかを示します。ゾーンに夏時間調整値が設定されていない場合は、この値は無視されます。

戻り値の分解された時間は、sbd-time の値を通常の範囲内に収め、その時間帯の実際の夏時間ルールをゾーン内で適用することで正規化します（これは sbd-time の値とは異なる場合があります）。これを最も簡単に理解するには、sbd-time にゾーンを追加して整数の UTC 時刻に変換し、次に `localtime` を適用して、その時刻をゾーン内で通常の形式で表示する、と考えると良いでしょう。

Scheme手順: **tzset** [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-tzset)

C 関数: **scm\_tzset** () [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-scm_005ftzset)

`TZ`環境変数またはシステムデフォルト値からタイムゾーンを初期化します。タイムゾーンに依存する他のプロシージャによって自動的に実行されるため、通常はこのプロシージャを呼び出す必要はありません。

Scheme Procedure: **strftime** format tm [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-strftime)

C 関数: **scm\_strftime** (format, tm) [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-scm_005fstrftime)

指定されたフォーマット文字列に従ってフォーマットされた、分解された時間構造の文字列を返します。

format には、'%' 文字で始まるフィールド指定が含まれます。使用可能なフォーマットについては、GNU C ライブラリ リファレンス マニュアルの [Formatting Calendar Time](https://doc.guix.gnu.org/libc/latest/en/libc.html#Formatting-Calendar-Time) または 'man 3 strftime' を参照してください。

([strftime](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-strftime) "%c" ([localtime](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-localtime) ([current-time](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-current_002dtime))))
⇒ 「2002年3月11日（月）20時17分43秒」

`setlocale` が呼び出されている場合 ([Locales](https://doc.guix.gnu.org/guile/latest/en/guile.html#Locales) を参照)、月と日の名前は現在のロケールから取得され、ロケールの文字セットで表示されます。

Scheme手順: **strptime** フォーマット文字列 [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-strptime)

C 関数: **scm\_strptime** (format, string) [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-scm_005fstrptime)

`strftime` の逆の操作を実行し、format で指定された仕様に従って文字列を解析します。月と日の名前の解釈は、現在のロケールに依存します。返される値はペアです。CAR には、`localtime` または `gmtime` によって返される形式の時間コンポーネントを持つオブジェクトがありますが、タイムゾーンコンポーネントは有効に設定されていません。CDR は、変換に使用された文字列の文字数を報告します。

変数: **internal-time-units-per-second** [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-internal_002dtime_002dunits_002dper_002dsecond)

この変数の値は、以下の手順によって報告される1秒あたりの時間単位数です。
