#### 7.5.6 SRFI-6 - 基本文字列ポート

SRFI-6では、`open-input-string`、`open-output-string`、`get-output-string`というプロシージャが定義されています。これらのプロシージャはGuileのコアライブラリに含まれているため、現時点ではこのモジュールを使用しても違いはありません。しかし、将来的にSRFI-6のサポートがコアライブラリから切り離される可能性もあるため、このモジュールを使用しても特に問題はありません。
