#### 6.6.14 VLists [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#VLists-1)

`(ice-9 vlist)`モジュールは、Phil Bagwellが2002年に設計した_VList_データ構造の実装を提供します。VListは、あらゆるSchemeオブジェクトを格納できる不変リストです。VListは、いくつかの点で標準的なSchemeリンクリストを改良しています。

* ランダムアクセスは通常、定数時間計算量です。
* VListの長さを計算する時間計算量は、要素数の対数に比例します。
* VListは標準リストよりもストレージ容量を少なく使用します。
* VListの要素は連続した領域に格納されるため、メモリの局所性が向上し、ハードウェアキャッシュをより効率的に使用できます。

VList の基本的な考え方は、vlist の要素を、徐々に大きくなる連続したブロック (ここではベクトルとして実装) に格納することです。これらのブロックは、次のブロックへのポインタと、そのブロック内のオフセットを使用して相互にリンクされます。これらのブロックのサイズは、`block-growth-factor` (デフォルトでは 2) の比率を持つ等比数列を形成します。

VList 構造は、_VList ベースのハッシュ リスト_、または「vHashes」と呼ばれる不変の辞書型の基礎としても機能します ([VList ベースのハッシュ リストまたは「VHashes」](https://doc.guix.gnu.org/guile/latest/en/guile.html#VHashes) を参照)。

しかし、現在の`(ice-9 vlist)`の実装には、いくつか注目すべき欠点があります。

* スレッドセーフではありません。vlist に対する操作はすべて参照透過的（つまり、純粋関数型）ですが、`vlist-cons` を使用して vlist に要素を追加すると、内部構造の一部が変更されるため、スレッドセーフではなくなります。これは修正可能ですが、`vlist-cons` の処理速度が低下します。
* `vlist-cons` は常に `cons` と同等以上のメモリを割り当てます。Phil Bagwell 氏が修正方法を説明していますが、そのためにはガベージコレクターを調整する必要があり、必ずしも一般的に有益とは限りません。
* `vlist-cons` はバイトコードにコンパイルされた Scheme プロシージャであり、`cons` の直接的な C 実装や VM に特別な `cons` 命令があるという事実とは競合しません。

今後、これらの問題に取り組んでいきたいと考えています。

`(ice-9 vlist)`によってエクスポートされるプログラミングインターフェースは、以下に定義されています。そのほとんどはSRFI-1と同じですが、関数名に`vlist-`という接頭辞が追加されています。

スキームプロシージャ: **vlist?** obj [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-vlist_003f)

objがVListであればtrueを返します。

スキーム変数: **vlist-null** [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-vlist_002dnull)

空のVList。空のVListは`eq?`と`vlist-null`に等しくない場合もあるため、VListが空かどうかをテストする際は、呼び出し元は常に`vlist-null?`を使用する必要があります。

スキーム手順: **vlist-null?** vlist [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-vlist_002dnull_003f)

vlistが空の場合はtrueを返します。

スキーム手順: **vlist-cons** item vlist [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-vlist_002dcons)

アイテムを先頭、vlistを末尾とする新しいvlistを返します。

スキーム手順: **vlist-head** vlist [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-vlist_002dhead)

vlistの先頭を返します。

スキーム手順: **vlist-tail** vlist [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-vlist_002dtail)

vlistの末尾を返します。

スキーム変数: **block-growth-factor** [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-block_002dgrowth_002dfactor)

VListブロックの成長率を定義する流体。デフォルト値は2。

以下の関数は、一般的な高レベルなリスト操作を提供します。

スキームプロシージャ: **vlist-fold** proc init vlist [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-vlist_002dfold)

スキーム手順: **vlist-fold-right** proc init vlist [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-vlist_002dfold_002dright)

SRFI-1の`fold`および`fold-right`と同様に、vlistを折り返し、各要素に対してprocを呼び出します（ [`fold`](https://doc.guix.gnu.org/guile/latest/en/guile.html#SRFI_002d1)を参照）。

スキーム手順: **vlist-ref** vlist インデックス [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-vlist_002dref)

vlist内のインデックスindexにある要素を返します。これは通常、定数時間で実行される操作です。

スキーム手順: **vlist-length** vlist [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-vlist_002dlength)

vlistの長さを返します。通常、これはvlistの要素数の対数になります。

スキーム手順: **vlist-reverse** vlist [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-vlist_002dreverse)

元のvlistの内容を逆順にした新しいvlistを返します。

スキーム手順: **vlist-map** proc vlist [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-vlist_002dmap)

vlistの要素に対してマップ処理を行い、新しいvlistを返します。

スキーム手順: **vlist-for-each** proc vlist [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-vlist_002dfor_002deach)

vlistの各要素に対してprocを呼び出します。結果は未定義です。

スキーム手順: **vlist-drop** vlist 数 [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-vlist_002ddrop)

vlistの最初のcount個の要素を含まない新しいvlistを返します。これは通常、定数時間で実行される操作です。

スキーム手順: **vlist-take** vlist 数 [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-vlist_002dtake)

vlistの最初のcount個の要素のみを含む新しいvlistを返します。

スキーム手順: **vlist-filter** pred vlist [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-vlist_002dfilter)

予測を満たすvlistのすべての要素を含む新しいvlistを返します。

スキーム手順: **vlist-delete** x vlist \[equal?\] [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-vlist_002ddelete)

要素が x と等しい vlist を除いた、vlist に対応する新しい vlist を返します。

スキーム手順: **vlist-unfold** pfg seed \[tail-gen\] [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-vlist_002dunfold)

Scheme Procedure: **vlist-unfold-right** pfg seed \[tail\] [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-vlist_002dunfold_002dright)

SRFI-1 の `unfold` および `unfold-right` と同様に、新しい vlist を返します ([`unfold`](https://doc.guix.gnu.org/guile/latest/en/guile.html#SRFI_002d1) を参照)。

スキーム手順: **vlist-append** vlist … [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-vlist_002dappend)

指定されたvlistを連結し、結果として得られるvlistを返します。

Scheme手順: **list->vlist** lst [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-list_002d_003evlist)

lstに対応する内容を持つ新しいvlistを返します。

スキーム手順: **vlist->list** vlist [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#index-vlist_002d_003elist)

vlistの内容と一致する新しいリストを返します。
