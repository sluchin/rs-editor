#### 7.5.32 SRFI-46 基本構文規則の拡張 [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#SRFI_002d46-Basic-syntax_002drules-Extensions)

Guile のコア `syntax-rules` は、SRFI-46/R7RS で規定されている拡張機能をサポートしています。末尾パターンは少なくとも Guile 2.0 以降でサポートされており、カスタム省略記号識別子は Guile 2.0.10 以降でサポートされています。[Syntax-rules Macros](https://doc.guix.gnu.org/guile/latest/en/guile.html#Syntax-Rules) を参照してください。
