#### 7.5.32 SRFI-46 基本構文規則の拡張

Guile のコア `syntax-rules` は、SRFI-46/R7RS で規定されている拡張機能をサポートしています。末尾パターンは少なくとも Guile 2.0 以降でサポートされており、カスタム省略記号識別子は Guile 2.0.10 以降でサポートされています。[Syntax-rules Macros](06_08_macros.md#682-構文規則マクロ) を参照してください。
