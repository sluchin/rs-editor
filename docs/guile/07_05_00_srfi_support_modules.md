### 7.5 SRFI サポート モジュール [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#SRFI-Support-Modules)

SRFIはScheme Request For Implementationの略です。SRFI文書では、R5RSで定義されている標準Schemeに対する多くの構文および手続きの拡張が定義されています。

Guileは多数のSRFIをサポートしています。この章では、利用可能なSRFIの概要と使用上のヒントについて説明します。完全なドキュメント、設計の根拠、その他の例については、SRFIホームページ[http://srfi.schemers.org/](http://srfi.schemers.org/)から関連するSRFIドキュメントを入手することをお勧めします。
