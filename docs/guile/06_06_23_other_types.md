#### 6.6.23 その他の型 [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#Other-Types-1)

手順については、専用のセクションに記載されています。[手順](https://doc.guix.gnu.org/guile/latest/en/guile.html#Procedures)を参照してください。

変数オブジェクトは、Guile のモジュールシステムの説明の一部として文書化されています。[変数](https://doc.guix.gnu.org/guile/latest/en/guile.html#Variables) を参照してください。

スレッド、ミューテックスなどについては、[スレッド、ミューテックス、非同期処理、動的ルート](https://doc.guix.gnu.org/guile/latest/en/guile.html#Scheduling)を参照してください。

ポートについては、I/O のセクションで説明しています。[入力と出力](https://doc.guix.gnu.org/guile/latest/en/guile.html#Input-and-Output) を参照してください。

正規表現については、専用のセクションで説明しています。[正規表現](https://doc.guix.gnu.org/guile/latest/en/guile.html#Regular-Expressions) を参照してください。

このマニュアルには、他にも多くのデータ型が記載されています。もしここに記載されていないリンクがあると思われる場合は、バグ報告をお願いします。
