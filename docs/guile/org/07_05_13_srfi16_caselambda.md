#### 7.5.13 SRFI-16 - case-lambda [¶](07_05_13_srfi16_caselambda.md#7513-srfi-16---case-lambda)

SRFI-16 defines a variable-arity `lambda` form, `case-lambda`. This form is available in the default Guile environment. See [Case-lambda](06_07_procedures.md#675-case-lambda), for more information.
