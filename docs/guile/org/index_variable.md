Variable Index [¶](index_variable.md)
----------------------------------------------------------------------------------------

This is an alphabetical list of all the important variables and constants in Guile.

When looking for a particular variable or constant, please look under its Scheme name as well as under its C name. The C name can be constructed from the Scheme names by a simple transformation described in the section See [Overview of the Guile API](06_01_overview_of_the_guile_api.md#61-overview-of-the-guile-api).
