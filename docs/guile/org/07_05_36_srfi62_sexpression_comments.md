#### 7.5.36 SRFI-62 - S-expression comments. [¶](07_05_36_srfi62_sexpression_comments.md#7536-srfi-62---s-expression-comments)

Starting from version 2.0, Guile’s `read` supports SRFI-62/R7RS S-expression comments by default.
