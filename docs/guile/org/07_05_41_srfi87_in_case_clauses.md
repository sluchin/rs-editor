#### 7.5.41 SRFI-87 => in case clauses [¶](07_05_41_srfi87_in_case_clauses.md#7541-srfi-87--in-case-clauses)

Starting from version 2.0.6, Guile’s core `case` syntax supports `=>` in clauses, as specified by SRFI-87/R7RS. See [Simple Conditional Evaluation](06_11_controlling_the_flow_of_program_execution.md#6112-simple-conditional-evaluation).
