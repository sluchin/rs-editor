#### 7.5.7 SRFI-8 - receive [¶](07_05_07_srfi8_receive.md#757-srfi-8---receive)

`receive` is a syntax for making the handling of multiple-value procedures easier. It is documented in See [Returning and Accepting Multiple Values](06_11_controlling_the_flow_of_program_execution.md#6117-returning-and-accepting-multiple-values).
