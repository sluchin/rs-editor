#### 7.5.8 SRFI-9 - define-record-type [¶](07_05_08_srfi9_definerecordtype.md#758-srfi-9---define-record-type)

This SRFI is a syntax for defining new record types and creating predicate, constructor, and field getter and setter functions. It is documented in the “Data Types” section of the manual (see [SRFI-9 Records](06_06_16_srfi9_records.md#6616-srfi-9-records)).
