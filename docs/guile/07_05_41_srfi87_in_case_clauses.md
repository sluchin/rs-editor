#### 7.5.41 SRFI-87 => in case 句

バージョン2.0.6以降、Guileのコア`case`構文は、SRFI-87/R7RSで規定されているように、句の中で`=>`をサポートしています。[単純な条件評価](06_11_controlling_the_flow_of_program_execution.md#6112-単純な条件評価)を参照してください。
