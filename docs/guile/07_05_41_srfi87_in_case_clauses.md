#### 7.5.41 SRFI-87 => in case 句 [¶](https://doc.guix.gnu.org/guile/latest/en/guile.html#SRFI_002d87-_003d_003e-in-case-clauses)

バージョン2.0.6以降、Guileのコア`case`構文は、SRFI-87/R7RSで規定されているように、句の中で`=>`をサポートしています。[単純な条件評価](https://doc.guix.gnu.org/guile/latest/en/guile.html#Conditionals)を参照してください。
