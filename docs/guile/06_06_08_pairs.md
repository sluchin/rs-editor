#### 6.6.8 ペア

ペアは、2つのSchemeオブジェクトを1つの複合オブジェクトに結合するために使用されます。そのため、ペアという名前が付けられています。ペアは、2つのオブジェクトを格納します。

Scheme では、他の Lisp 方言と同様に、データ型 _pair_ が非常に重要です。その理由は、ペアは 2 つの値を 1 つのオブジェクトとして利用できるようにするために使われるだけでなく、値のリストを構築するためにも使われるからです。リストは Scheme で非常に重要なので、専用のセクションで説明されています ([Lists](06_06_09_lists.md#669-リスト) を参照)。

ペアは、ソースコードまたは REPL で、いわゆるドット付きリスト構文を使用して直接入力できます。この構文は、開き括弧、ペアの最初の要素、ドット、2 番目の要素、閉じ括弧で構成されます。次の例は、2 つの数値 1 と 2 からなるペア、および記号 `foo` と `bar` を含むペアの入力方法を示しています。ドットの前後に空白を記述することが非常に重要です。そうしないと、Scheme パーサーがトークンをどこで分割すればよいかを判断できなくなるためです。

（1.2）
(foo.bar)

ただし、これらの例を試す場合は、式を引用符で囲む必要があることに注意してください。引用符に関する詳細は、[式の構文](06_16_reading_and_evaluating_scheme_code.md#61611-式の構文) のセクションを参照してください。これらの例を正しく試す方法は次のとおりです。

（1.2）
⇒
（1.2）
'(foo . bar)
⇒
(foo.bar)

新しいペアは、2つの引数を指定してプロシージャ`cons`を呼び出すことで作成されます。引数の値は新しく割り当てられたペアに格納され、そのペアが返されます。`cons`という名前は「構築する」という意味です。指定されたSchemeオブジェクトがペアであるかどうかをテストするには、プロシージャ`pair?`を使用します。

スキーム手順: **cons** xy

C 関数: **scm\_cons** (x, y)

車両がx、CDRがyである、新たに割り当てられたペアを返します。このペアは、以前に存在したすべてのオブジェクトと（`eq?`の意味で）異なることが保証されています。

スキーム手順: **pair?** x

C 関数: **scm\_pair\_p** (x)

xがペアの場合は`#t`を返し、そうでない場合は`#f`を返します。

C 関数: `int` **scm\_is\_pair** `(SCM x)`

xがペアの場合は1を返し、そうでない場合は0を返します。

ペアを構成する2つの要素は、従来は _car_ と _cdr_ と呼ばれています。これらは、同じ名前のプロシージャ (`car` と `cdr`) を使用して取得でき、プロシージャ `set-car!` と `set-cdr!` を使用して変更できます。

Scheme プログラムでは、ペアの car の car や cdr の car などにアクセスする操作が非常に一般的であるため、`caar`、`cadr` などのプロシージャも事前に定義されています。しかし、これらのプロシージャを使用すると、可読性が損なわれ、エラーが発生しやすくなります。そのため、リストの内容にアクセスするには、パターンマッチング技術を使用する方が通常は優れています ([パターンマッチング](07_08_pattern_matching.md#78-パターンマッチング) を参照)。

これらのマクロは一切チェックを行いません。引数のペアは有効なペアでなければなりません。

これらの手順は `car` と `cdr` の組み合わせであり、例えば `caddr` は次のように定義できます。

(define [caddr](#668-ペア) (lambda (x) ([car](#668-ペア) ([cdr](#668-ペア) ([cdr](#668-ペア) x)))))

`cadr`、`caddr`、`cadddr`は、それぞれリストの2番目、3番目、4番目の要素を選択します。SRFI-1では、同じ機能が`second`、`third`、`fourth`という名前で提供されています（[セレクタ](07_05_03_srfi1_list_library.md#7533-セレクタ)を参照）。
