# 1. はじめに

> **原文**: [Guile Reference Manual - Introduction](https://www.gnu.org/software/guile/manual/guile.html#Introduction)
> 
> このドキュメントはGNU Free Documentation Licenseの下で公開されています。

Guile は Scheme プログラミング言語の実装です。Scheme は Lisp の優雅で概念的にシンプルな方言で、Guy Steele と Gerald Sussman によって創始され、RnRS（Revised^n Reports on Scheme）として知られる一連のレポートによって進化してきました。

## 1.1 Guile と Scheme

Guile は Revised^5 Report on the Algorithmic Language Scheme（通常 R5RS として知られています）で説明されている Scheme を実装しており、クリーンで汎用的なデータとコントロール構造を提供しています。Guile は R5RS で提示されたやや質素な言語を超えており、以下の機能で拡張されています：

- モジュールシステム
- POSIX システムコールへの完全なアクセス
- ネットワークサポート
- マルチスレッド
- 動的リンク
- 外部関数呼び出しインターフェース
- 強力な文字列処理
- 実世界のプログラミングに必要な多くの他の機能

Scheme コミュニティは 2007 年に R6RS を合意して発表しました。R6RS は Scheme のコア言語を拡張し、多くの非コア機能を標準化しています。Guile は時間をかけて、R6RS のほぼすべての機能を組み込むように更新されてきました。

### Guile の特徴

Guile の特徴として以下が挙げられます：

1. **C との組み合わせが容易** - C で書かれた他のコードと簡単に組み合わせることができます
2. **GNU プロジェクトとの歴史的なつながり** - GNU エコシステムの一部です
3. **対話型・漸進型プログラミングの強調** - REPL での作業が得意です
4. **複数の言語をサポート** - Scheme だけでなく、複数の言語に対応しています

## 1.2 C コードとの結合

Guile は C コードとの結合が簡単に行えるように設計されており、既存の C プログラムに Scheme スクリプト機能を追加したり、Scheme から C ライブラリを呼び出したりできます。

## 1.3 Guile と GNU プロジェクト

Guile は GNU プロジェクトの公式拡張言語として位置づけられており、GNU の様々なツールとの統合が考慮されています。

## 1.4 対話型プログラミング

Guile は対話型のプログラミング環境（REPL）を提供し、コードをリアルタイムで実行・テストできます。これによってプログラムの開発がより迅速で効率的になります。

## 1.5 複数の言語のサポート

Guile は Scheme だけでなく、Emacs Lisp や ECMAScript など複数の言語もサポートしており、異なる言語のコードを同じ環境で実行できます。

## 1.6 Guile の入手とインストール

Guile は以下の方法で入手できます：

- **公式ウェブサイト**: https://www.gnu.org/software/guile/
- **Linux ディストリビューション**: ほぼすべてのディストリビューション（Debian, Fedora, Arch など）のパッケージマネージャーで利用可能
- **ソースからのビルド**: ソースコードから自分でビルドすることもできます

## 1.7 このマニュアルの構成

このマニュアルは以下のように構成されています：

1. **基本的な概念** - Guile の基本的な使用方法と概念
2. **Scheme 言語** - Scheme プログラミング言語の解説
3. **Guile API リファレンス** - Guile が提供する詳細な API
4. **実装ガイド** - C との統合、モジュール開発などの高度なトピック

## 1.8 表記規則

このマニュアルで使用する表記規則：

- `code` - プログラムコードまたは関数名
- `filename` - ファイル名またはパス
- **太字** - 重要な概念や用語
- *イタリック* - 強調
