# 第1章 セットアップ

> 解説ノートです。原文は https://viewsourcecode.org/snaptoken/kilo/ （© Paul Smith, CC BY 4.0）にあります。

## この章で作るもの

C コンパイラと `make` を使い、何もしない最小の C プログラムをビルドできる状態にします。エディタとしての機能はまだありません。

## 必要なもの

- C コンパイラ（gcc または clang）
- `make`
- Unix 系のターミナル（Linux、macOS、WSL など）

このエディタは、curses のようなライブラリを使わず、ターミナルに直接エスケープシーケンスを書き出します。そのため、標準ライブラリと POSIX の API だけで足ります。

## 手順の流れ

### 1. `main` だけのプログラム

`kilo.c` に、何もせず 0 を返す `main` だけを書きます。ここでの目的は、ビルドと実行の流れを確認することです。

### 2. Makefile

コンパイルのたびに長いコマンドを打たなくて済むよう、`make` でビルドできるようにします。レシピには次のようなオプションを付けます。

- `-Wall -Wextra -pedantic`: 警告を多めに出して、うっかりを早く見つける
- `-std=c99`: 使う C の規格を固定する

```make
kilo: kilo.c
	$(CC) kilo.c -o kilo -Wall -Wextra -pedantic -std=c99
```

レシピの行頭はスペースではなくタブでなければならない点に注意してください。

## 確認ポイント

- `make` で `kilo` という実行ファイルができる
- `./kilo` が何も表示せずに終了する
