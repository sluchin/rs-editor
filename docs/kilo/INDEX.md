# Kilo エディタ ドキュメント索引

このディレクトリには, Kilo テキストエディタの日本語ドキュメントが含まれています. Kilo は教育的なテキストエディタで, ターミナル制御やエディタアーキテクチャを学ぶのに最適です.

## 学習パス

### 初級: Kilo を使い始める
1. README.md を読む.
2. Kilo をインストールしてテキストファイルを編集してみる.
3. キーバインディングを試す.

### 中級: Kilo の内部構造を理解する
1. ARCHITECTURE.md でモジュール構成を理解.
2. TERMINAL_CONTROL.md でターミナル制御の仕組みを学ぶ.
3. SYNTAX_HIGHLIGHTING.md でハイライトシステムを理解.

### 上級: 独自実装
1. IMPLEMENTATION_GUIDE.md で段階的な実装を学ぶ.
2. フェーズ 1 から段階的に実装.
3. 各フェーズで自分の環境で試す.

## トラブルシューティング

### よくある質問

**Q: Kilo はどの言語で実装されていますか？**
A: C 言語で実装されています. C 標準ライブラリのみに依存しています.

**Q: Kilo の主な用途は何ですか？**
A: 教育目的です. テキストエディタの実装方法を学ぶのに最適です.

**Q: Kilo を商用プロダクションで使用できますか？**
A: 技術的には可能ですが, Vim や Emacs などのプロダクション級エディタの方が適しています.

**Q: Kilo に Undo/Redo 機能はありますか？**
A: 基本的な実装には含まれていません. IMPLEMENTATION_GUIDE.md で追加方法を説明しています.
