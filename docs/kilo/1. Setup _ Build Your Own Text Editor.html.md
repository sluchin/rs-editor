![レゴの組み立て説明書のステップ1：レゴブロック1個](./1. セットアップ_独自のテキストエディタを作成する_files/lego-step-one.png)

ああ、ステップ1ですね。まっさらな状態から新たなスタートを切るのは、最高じゃないですか？そして、その上に築く壮大な邸宅の土台となる、たった一つのレンガを選ぶのは？

残念ながら、コンピュータプログラムを作成する際、最初のステップは複雑で、しかもイライラさせられることがあります。使用するプログラミング言語に対応した環境が整っていることを確認し、その環境でプログラムをコンパイルして実行する方法を理解しなければならないからです。

幸いなことに、今回作成するプログラムは外部ライブラリに依存しないため、Cコンパイラと標準ライブラリ以外には何も必要ありません。（`make`プログラムも使用します。）Cコンパイラがインストールされているかどうかを確認するには、コマンドラインで`cc --version`を実行してみてください（`cc`は「C Compiler」の略です）。`make`がインストールされているかどうかを確認するには、`make -v`を実行してみてください。

### […Windowsの場合](https://viewsourcecode.org/snaptoken/kilo/01.setup.html#in-windows)

Windows 内に何らかの Linux 環境をインストールする必要があります。これは、テキスト エディタが `<termios.h>` ヘッダーを使用して低レベルでターミナルとやり取りするためですが、このヘッダーは Windows では利用できません。Windows 上の Bash または Cygwin を使用することをお勧めします。

**Windows での Bash**: 64 ビット版 Windows 10 でのみ動作します。[インストール ガイド](https://msdn.microsoft.com/en-us/commandline/wsl/install_guide) を参照してください。インストール後、Linux 環境に入るときはいつでもコマンドラインで `bash` を実行します。`bash` 内で `sudo apt-get install gcc make` を実行して、GNU コンパイラ コレクションと `make` プログラムをインストールします。`sudo` の実行に非常に時間がかかる場合は、[/etc/hosts ファイルを修正](https://superuser.com/questions/1108197) する必要があるかもしれません。

**Cygwin**: [cygwin.com/install.html](https://cygwin.com/install.html) からインストーラーをダウンロードしてください。インストーラーがインストールするパッケージを選択するように求めてきたら、`devel` カテゴリを探し、`gcc-core` と `make` パッケージを選択してください。Cygwin を使用するには、Cygwin ターミナル プログラムを実行する必要があります。Windows の Bash とは異なり、Cygwin ではホーム ディレクトリは Windows のホーム ディレクトリとは別になっています。Cygwin を `C:\cygwin64` にインストールした場合、ホーム ディレクトリは `C:\cygwin64\home\yourname` になります。そのため、Cygwin 以外のテキスト エディタを使用してコードを記述する場合は、ここに保存する必要があります。

### […macOSの場合](https://viewsourcecode.org/snaptoken/kilo/01.setup.html#in-macos)

`cc`コマンドを実行しようとすると、コマンドライン開発者ツールをインストールするかどうかを尋ねるウィンドウが表示されます。`xcode-select --install`を実行しても、このウィンドウが表示されます。あとは「インストール」をクリックするだけで、Cコンパイラや`make`などがインストールされます。

### […Linuxの場合](https://viewsourcecode.org/snaptoken/kilo/01.setup.html#in-linux)

Ubuntuでは、`sudo apt-get install gcc make` を実行します。他のディストリビューションでも、`gcc`と`make`のパッケージは利用できるはずです。

[`main()`関数](https://viewsourcecode.org/snaptoken/kilo/01.setup.html#the-main-function)
--------------------------------------------------------------------------------------------------

`kilo.c`という名前の新しいファイルを作成し、その中に`main()`関数を追加してください。（`kilo`は、これから作成するテキストエディタの名前です。）

[kilo.c](https://github.com/snaptoken/kilo-src/blob/main/kilo.c)

ステップ1

[メイン](https://github.com/snaptoken/kilo-src/tree/main)

int main() { return 0;}

♐ ︎ コンパイル

C言語では、実行可能なコードはすべて関数の中に記述する必要があります。C言語の`main()`関数は特別な関数です。これはプログラム実行時のデフォルトの開始点となります。`main()`関数から`return`すると、プログラムは終了し、返された整数値をオペレーティングシステムに渡します。戻り値が`0`の場合は成功を示します。

C言語はコンパイル言語です。つまり、プログラムをCコンパイラに通して実行可能ファイルに変換する必要があります。その後、その実行可能ファイルをコマンドライン上で他のプログラムと同様に実行します。

`kilo.c`をコンパイルするには、シェルで`cc kilo.c -o kilo`を実行してください。エラーが発生しなければ、`kilo`という名前の実行ファイルが生成されます。`-o`は「出力」を意味し、出力される実行ファイルの名前を`kilo`にすることを指定します。

`kilo`を実行するには、シェルで`./kilo`と入力してEnterキーを押してください。このプログラムは何も出力しませんが、`echo $?`を実行することで終了ステータス（`main()`が返す値）を確認できます。`echo $?`を実行すると`0`が出力されるはずです。

[`make` を使用したコンパイル](https://viewsourcecode.org/snaptoken/kilo/01.setup.html#compiling-with-make)
----------------------------------------------------------------------------------------------------

コンパイルするたびに `cc kilo.c -o kilo` と入力するのは面倒です。`make` プログラムを使えば、`make` を実行するだけでプログラムが自動的にコンパイルされます。コンパイル方法を指定する `Makefile` を用意するだけで済みます。

`Makefile` という名前の新しいファイルを作成し、以下の内容を記述してください。

[Makefile](https://github.com/snaptoken/kilo-src/blob/make/Makefile)

ステップ2

[make](https://github.com/snaptoken/kilo-src/tree/make)

キロ: キロ.c 	$(CC) キロ.c -o キロ -Wall -Wextra -pedantic -std=c99

♐ ︎ コンパイル

最初の行は、`kilo` をビルドしたいこと、そして `kilo.c` をビルドするために必要なファイルであることを示しています。2行目は、`kilo.c` から実際に `kilo` をビルドするために実行するコマンドを指定しています。2行目は、スペースではなくタブ文字でインデントしてください。C ファイルのインデント方法は自由ですが、`Makefile` はタブを使用する必要があります。

コンパイルコマンドにいくつかの項目を追加しました。

* `$(CC)` は、`make` がデフォルトで `cc` に展開する変数です。
* `-Wall` は「**すべての** **警告**」を意味し、コンパイラがプログラム内のコードで、技術的には間違っていないかもしれないが、C 言語の不適切な使用法または疑わしい使用法と見なされるものを見つけた場合に警告を発するようにします。たとえば、変数を初期化する前に使用するなどです。
* `-Wextra` と `-pedantic` オプションを有効にすると、さらに多くの警告が表示されます。このチュートリアルの各ステップで、プログラムがコンパイルされれば、場合によっては「未使用変数」に関する警告を除いて、警告は発生しないはずです。その他の警告が表示された場合は、コードがそのステップのコードと完全に一致していることを確認してください。
* `-std=c99` は、使用する C 言語の標準規格の正確なバージョンを指定します。これは [C99](https://en.wikipedia.org/wiki/C99) です。C99 では、関数内のどこでも変数を宣言できますが、[ANSI C](https://en.wikipedia.org/wiki/ANSI_C) では、すべての変数を関数またはブロックの先頭で宣言する必要があります。

`Makefile`ができたので、`make`を実行してプログラムをコンパイルしてみましょう。

出力は「make: `kilo' は最新です」となる場合があります。これは、各ファイルの最終更新日時を確認することで、`kilo.c` の現在のバージョンが既にコンパイル済みかどうかを判断できます。`kilo` が `kilo.c` の最終更新後に最後に更新された場合、`make` は `kilo.c` が既にコンパイル済みであると想定し、コンパイル コマンドを実行しません。`kilo.c` が `kilo` の最終更新後に最後に更新された場合、`make` は `kilo.c` を再コンパイルします。これは、コンパイルするコンポーネントが多数ある大規模プロジェクトでより役立ちます。1 つのコンポーネントのソース コードのみを変更する場合、ほとんどのコンポーネントを何度も再コンパイルする必要がないためです。

`kilo.c` の戻り値を `0` 以外の数値に変更してみてください。次に `make` を実行すると、コンパイルが成功するはずです。`./kilo` を実行し、`echo $?` を実行して、変更した数値が表示されるかどうかを確認してください。その後、戻り値を `0` に戻して再コンパイルし、戻り値が `0` に戻っていることを確認してください。

このチュートリアルの各ステップの後には、`kilo.c` を再コンパイルし、コードにエラーがないか確認してから、`./kilo` を実行する必要があります。再コンパイルを忘れて `./kilo` だけを実行し、`kilo.c` への変更が反映されないことに疑問を感じることはよくあります。`kilo.c` の変更を `kilo` に反映させるには、必ず再コンパイルが必要です。
