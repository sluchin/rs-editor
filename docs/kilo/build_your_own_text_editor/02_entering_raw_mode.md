# 第2章 raw モードに入る

> 解説ノートです。原文は https://viewsourcecode.org/snaptoken/kilo/ （© Paul Smith, CC BY 4.0）にあります。

## この章のテーマ

ターミナルは標準では、Enter が押されるまで入力をためてからプログラムに渡します（canonical モード）。エディタでは 1 キーごとに反応したいので、この挙動を止める必要があります。この章では `termios` を使って端末の設定を書き換え、キーを 1 つずつ受け取れる raw モードにします。

## 手順の流れ

### 1. 標準入力を 1 バイトずつ読む

`read()` で標準入力から 1 バイトずつ読むループを作ります。最初は、Enter を押すまで何も反応しません。また、`q` を押しても終了しないことが分かります。これが canonical モードです。

### 2. `q` で終了する

読んだ文字が `q` ならループを抜けます。ただし、`q` の後ろに続けて入力した文字は、終了後にシェルへ流れ込みます。端末側がまだ行単位の設定のままだからです。

### 3. エコーを止める

`tcgetattr()` で現在の設定を取得し、`ECHO` フラグを落として `tcsetattr()` で反映します。パスワード入力のように、打った文字が画面に出なくなります。

設定は終了時に元へ戻す必要があります。元の設定を保存しておき、`atexit()` で復元する関数を登録します。

### 4. canonical モードを止める

`ICANON` フラグを落とすと、Enter を待たずに 1 バイトずつ読めます。`q` を押した瞬間に終了するようになります。

### 5. 各種のフラグを順に落とす

| フラグ | 落とす理由 |
|---|---|
| `ISIG` | Ctrl-C / Ctrl-Z によるシグナルを受け取らず、キーとして扱う |
| `IXON` | Ctrl-S / Ctrl-Q による出力の停止・再開を無効にする |
| `IEXTEN` | Ctrl-V などの拡張入力を無効にする |
| `ICRNL` | Enter（Ctrl-M）を勝手に改行コードへ変換させない |
| `OPOST` | 出力時の `\n` → `\r\n` の変換をやめる |

`OPOST` を落とすと、改行の後にカーソルが行頭へ戻らなくなります。そのため以降は、出力に `\r\n` を明示的に書きます。

あわせて、歴史的な理由で慣習的に落とす `BRKINT`、`INPCK`、`ISTRIP` と、8 ビット文字を指定する `CS8` も設定します。

### 6. 読み取りのタイムアウト

`VMIN`（最小バイト数）を 0、`VTIME`（待ち時間、単位は 1/10 秒）を 1 にします。入力がなくても約 0.1 秒で `read()` が戻るため、画面の更新など、入力待ち以外の処理を挟める土台になります。

### 7. エラー処理

`read()` などが失敗した場合に備え、画面を消してから `perror()` でメッセージを出し、異常終了する `die()` 関数を作ります。システムコールの戻り値は、その都度確認します。

## 確認ポイント

- 打ったキーが画面に出ず、押した瞬間に処理される
- Ctrl-C、Ctrl-S、Ctrl-Q を押しても、プログラムが止まらず、キーとして届く
- 終了後に、ターミナルの表示が元に戻っている
