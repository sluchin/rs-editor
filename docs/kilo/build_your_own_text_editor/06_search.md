# 第6章 検索

> 解説ノートです。原文は https://viewsourcecode.org/snaptoken/kilo/ （© Paul Smith, CC BY 4.0）にあります。

## この章のテーマ

検索機能を、まず単純な形で作り、それをインクリメンタル検索（入力のたびに結果が動く検索）へ発展させます。前章のプロンプトを、コールバックを受け取れる形へ拡張するのが鍵です。

## 手順の流れ

### 1. 基本の検索

Ctrl-F で、プロンプトに検索語を入力します。

- 各行の `render`（画面上の文字列）を `strstr()` で探す
- 見つかった行までスクロールし、カーソルを一致位置へ動かす
- `render` 上の位置は、ファイル上の位置とずれる（タブのため）ので、`rx` から `cx` へ戻す変換が要る

### 2. プロンプトにコールバックを付ける

入力のたびに処理を呼べるよう、プロンプトが関数ポインタを受け取るようにします。

- キーを 1 つ入力するたびに、現在の文字列と押されたキーを渡して呼ぶ
- 不要な場合は `NULL` を渡す
- 保存など、これまでの使い方は変えずに済む

### 3. インクリメンタル検索

コールバックの中で検索を行うと、1 文字打つたびに結果が更新されます。

- Esc または Enter が押されたら、検索を終了する
- 検索の状態（前回の一致位置、検索の向き）は、関数内の `static` 変数として保持する
- Esc でキャンセルしたときは、検索前のカーソル位置とスクロール位置へ戻す

### 4. 矢印キーで次・前の一致へ

矢印キー（右・下で次、左・上で前）に応じて、検索の向きを切り替えます。

- 前回の一致の次（または前）の行から探し始める
- 末尾まで行ったら先頭へ戻る（循環する）
- 一致が見つからなければ、何もしない

案内文に、操作方法（Esc / 矢印 / Enter）を表示します。

## 確認ポイント

- 検索語を打つたびに、一致位置へ移動する
- 矢印キーで、次の一致・前の一致へ移れる
- Esc でキャンセルすると、元の位置へ戻る
- タブを含む行でも、正しい位置に移動する
