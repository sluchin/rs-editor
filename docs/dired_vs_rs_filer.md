# Dired と rs-filer のキーの違い

Emacs 30 の dired の既定のキーと、rs-filer のキーを比べて、違うものを洗い出しました。

- dired: `emacs -Q` の `dired-mode-map` と、グローバルのキー（Emacs 30.2）。一覧は [KEYBINDINGS.md](keybindings.md) の「Dired」。
- rs-filer: `../rs-filer/src/features/keybindings/keymap.ts` の `DEFAULT_BINDINGS`（rs-filer 0.3.3）。rs-filer の `KEYBINDINGS.md` には、`C-n` / `C-p`（上下）と `<` / `>`（列の幅）が書かれていない。

rs-filer は 2 つのペインを持つファイラ（xyzzy のファイラが手本）で、dired は 1 つのバッファです。そのため、同じキーでも、働きが大きく違うものがあります。

## 1. 同じキーで、働きが違うもの

rs-editor に dired を作るとき、rs-filer の手癖とぶつかるキーです。

| キー | dired | rs-filer |
|------|-------|----------|
| `SPC` | 次の行へ (dired-next-line) | マークして下へ |
| `j` | 名前を入れて、その行へ (dired-goto-file) | 下へ |
| `k` | 行を表示から消す (dired-do-kill-lines) | 上へ |
| `h` | dired の説明 (describe-mode) | 親ディレクトリへ |
| `l` | 行を読み直す (dired-do-redisplay) | 開く |
| `g` | 一覧を読み直す (revert-buffer) | パスの入力欄へ |
| `m` | マーク (dired-mark) | 対向ペインへ移動 |
| `M` | 権限を変える (dired-do-chmod) | 対向ペインへ移動（必ず確認） |
| `R` | 名前の変更・移動 (dired-do-rename) | 再読み込み |
| `c` | アーカイブにまとめる (dired-do-compress-to) | 対向ペインへコピー |
| `C` | コピー (dired-do-copy) | 対向ペインへコピー（必ず確認） |
| `d` | 削除のフラグを付ける (dired-flag-file-deletion) | ゴミ箱へ（確認あり） |
| `D` | 削除 (dired-do-delete) | 完全に削除 |

| `e` | 開く（Emacs の中で） (dired-find-file) | 外部のエディタで開く |
| `f` | 開く（Emacs の中で） (dired-find-file) | 開く（ファイルは関連付けたアプリで） |
| `t` | マークを反転 (dired-toggle-marks) | ツリー表示の切り替え |

| `.` | 古いバックアップにフラグ (dired-clean-directory) | 隠しファイルの表示 / 非表示 |
| `~` | バックアップにフラグ (dired-flag-backup-files) | ホームへ |
| `<` / `>` | 前 / 次のディレクトリの行へ (dired-prev-dirline / next-dirline) | 列の幅を狭く / 広く |

## 2. 同じ働きで、キーが違うもの

| 働き | dired | rs-filer |
|------|-------|----------|
| 次の行 / 前の行 | `n` / `p`、`SPC` / `S-SPC`、`C-n` / `C-p` | `j` / `k`、`↓` / `↑`、`C-n` / `C-p` |
| 開く | `RET` / `e` / `f` | `RET` / `f` / `l` / `→` |
| 外部のアプリで開く | `E` | `x` |
| 親ディレクトリへ | `^` | `^` / `h` / `←` / `Backspace` |
| マーク | `m` / `* m` | `SPC` |
| マークを反転 | `t` / `* t` | `* t` |
| 全てマーク | （`* s` が近い） | `* *` / `C-a` |
| 全てのマークを外す | `U` / `* !` | `U` / `* u` |
| 名前の変更 | `R` | `r` / `F2` |
| 移動（別のディレクトリへ） | `R` | `m` / `M` |
| 削除 | `d` で印を付けて `x`、または `D` | `d`（ゴミ箱）/ `D`（完全に削除） |
| ディレクトリを作る | `+` | `+` / `N` |
| 一覧の読み直し | `g` | `R` / `F5` / `C-l` |
| 並べ替え | `s`（名前と日付の 2 つ） | `s`（名前、拡張子、サイズ、日付の昇順・降順を順に） |
| 詳細の表示 / 非表示 | `(` | `i` |
| ファイル名のコピー | `w`（`C-u 0 w` でフルパス） | `M-n`（名前）/ `M-w`（フルパス） |
| ファイル名で探す | `j`（名前を入れる）、`M-s f C-s` | `/` / `C-s`（絞り込み） |
| 中を見る | `v`（読むだけで開く）、`C-o`（別のウィンドウ） | `v`（対向ペインにプレビュー） |
| シェルのコマンド | `!` / `X`、`&`（非同期） | `X` / `&` |
| 名前の正規表現でマーク | `* %` / `% m` | `* s`（`/正規表現/`） |
| 別のウィンドウへ | `C-x o` | `Tab` / `C-x o` |
| 説明 | `?`（1 行）/ `h`（全て） | `?` |

## 3. dired にだけあるもの

rs-filer に、同じ働きのキーが無いものです。

- ディレクトリを開く: `C-x d`、`C-x 4 d`、`C-x 5 d`、`C-x C-j`（今のファイルのディレクトリ）、`C-x 4 C-j`
- 移動: `j`（名前で）、`<` / `>`（ディレクトリの行）、`M-{` / `M-}`（マークした行）、`C-M-n` / `C-M-p` / `C-M-u` / `C-M-d` / `M-G`（サブディレクトリ）
- 開く: `o`（別のウィンドウ）、`a`（バッファを置き換える）、`W`（ブラウザ）、`y`（ファイルの種類）
- サブディレクトリを同じバッファに足す: `i`、`$`、`M-$`
- 表示から消す・読み直す: `k`、`l`
- 削除のフラグ: `d` → `x` の 2 段、`#`、`~`、`.`、`% d`、`% &`
- マーク: `* /`（ディレクトリ）、`* @`（リンク）、`* *`（実行できるもの）、`% g`（中身で）、`* c`（マークの文字を変える）、`* N`（数とサイズ）、`DEL`、`M-DEL`
- リンク: `H`、`S`、`Y`
- 属性: `M`（chmod）、`G`（chgrp）、`O`（chown）、`T`（touch）
- 圧縮: `Z`、`c`
- 比べる: `=`（diff）
- 中身の検索・置換: `A`、`Q`、`M-s a C-s`
- 正規表現で名前を変える: `% R` / `% r`、`% C`、`% H` / `% S` / `% Y`、`% u` / `% l`
- 一覧を編集して名前を変える: `C-x C-q`（wdired）
- マークなどを元に戻す: `C-/` / `C-x u`
- GnuPG: `: e` / `: d` / `: s` / `: v`
- 画像のサムネイル: `C-t` で始まるキー
- Emacs のためのもの: `B`、`L`、`I`、`N`、`P`

## 4. rs-filer にだけあるもの

dired に、同じ働きのキーが無いものです（多くは 2 つのペインと、OS との連携のため）。

- 2 つのペイン: `Tab` / `C-i`（切り替え）、`O` / `C-x 4`（対向ペインを同じディレクトリに）、`c` / `m`（対向ペインへコピー・移動）、`v`（プレビュー）、`I`（詳細情報）
- ゴミ箱: `d` / `Delete`（dired は `delete-by-moving-to-trash` を `t` にしたとき）
- クリップボード（ファイル）: `C-c`、`C-v`
- 移動: `g` / `M-g`（パスの入力）、`~` / `H`（ホーム）、`M-d`（ドライブ）、`M-←` / `M-→`（履歴を戻る・進む）、`M-h`（履歴の一覧）、`b` / `M-b`（ブックマーク）
- 表示: `.` / `C-x .`（隠しファイル）、`t`（ツリー）、`<` / `>`（列の幅）、`M-t`（テーマ）、`M-0`（フォントの大きさ）
- 外部: `x`（関連付けたアプリ）、`e`（外部のエディタ）、`!` / `M-!`（ターミナル）
- そのほか: `C-x C-f`（新しいファイル）、`L`（操作ログ）、`:`（コマンドパレット）、`q` / `C-x C-c`（終了）、`PageUp` / `PageDown` / `Home` / `End`

## 5. 同じもの

| キー | 働き |
|------|------|
| `C-n` / `C-p` | 次の行 / 前の行 |
| `^` | 親ディレクトリへ |
| `RET` | 開く |
| `u` | マークを外す |
| `U` | 全てのマークを外す |
| `* t` | マークを反転 |
| `+` | ディレクトリを作る |
| `&` | コマンドを実行（dired は非同期のシェル、rs-filer は外部コマンド） |
| `s` | 並べ替えの切り替え（順の種類は違う） |
| `?` | キーの説明 |
| `M-<` / `M->` | 先頭 / 末尾へ |
| `M-v` | 1 画面前へ |
| `C-x o` | 別のウィンドウ（ペイン）へ |
| `M-x` | コマンドを名前で実行 |
| `C-g` | 取り消す |
| `C-x C-c` | 終了 |
