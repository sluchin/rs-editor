# 4. 組み込み手続き

Scheme インタプリタに組み込まれている関数（手続き）の一覧です。

## 算術演算

### `(+ num1 num2 ...)`

複数の数値を加算します。

**シグネチャ:**
```scheme
(+ [num1 num2 ...]) → number
```

**説明:**
すべての引数を加算し、その合計を返します。引数がない場合は 0 を返します。

**例:**
```scheme
(+ 1 2)         ; => 3
(+ 1 2 3 4 5)   ; => 15
(+ 10.5 0.5)    ; => 11
(+)             ; => 0  [加算の単位元]
(+ -5)          ; => -5
```

**エラー:**
```scheme
(+ 1 "2")       ; エラー: + expects numbers
```

### `(- num1 [num2 ...])`

最初の数値から残りの数値を順番に減算します。単一引数の場合は負数化します。

**シグネチャ:**
```scheme
(- num1 [num2 ...]) → number
```

**説明:**
- 引数が 1 個：その数値の負数を返す
- 引数が 2 個以上：最初の引数から残りを次々と減算

**例:**
```scheme
(- 10 3)        ; => 7     [10 - 3]
(- 5)           ; => -5    [負数化]
(- 100 20 10)   ; => 70    [100 - 20 - 10]
(- 0)           ; => 0
(- -5)          ; => 5
```

**エラー:**
```scheme
(-)             ; エラー: - expects at least one argument
(- 1 "2")       ; エラー: - expects numbers
```

### `(* num1 num2 ...)`

複数の数値を乗算します。

**シグネチャ:**
```scheme
(* [num1 num2 ...]) → number
```

**説明:**
すべての引数を乗算し、その積を返します。引数がない場合は 1 を返します。

**例:**
```scheme
(* 2 3)         ; => 6
(* 2 3 4)       ; => 24
(* -5 3)        ; => -15
(*)             ; => 1  [乗算の単位元]
(* 0 100)       ; => 0
```

**エラー:**
```scheme
(* 1 "2")       ; エラー: * expects numbers
```

### `(/ num1 num2 [num3 ...])`

最初の数値を残りの数値で順番に除算します。ゼロ除算はエラー。

**シグネチャ:**
```scheme
(/ num1 num2 [num3 ...]) → number
```

**説明:**
- 最初の数値を 2 番目の数値で除算
- 結果をさらに 3 番目の数値で除算（以下続く）

**例:**
```scheme
(/ 20 4)        ; => 5     [20 ÷ 4]
(/ 100 2 5)     ; => 10    [100 ÷ 2 ÷ 5]
(/ 1 2)         ; => 0.5
(/ 1 3)         ; => 0.333...
```

**エラー:**
```scheme
(/)             ; エラー: / expects at least two arguments
(/ 1)           ; エラー: / expects at least two arguments
(/ 1 0)         ; エラー: / expects non-zero numbers
(/ 10 2 0)      ; エラー: / expects non-zero numbers
(/ 1 "2")       ; エラー: / expects numbers
```

## リスト操作

### `(quote expr)`

式をそのまま返します。評価しません。

**シグネチャ:**
```scheme
(quote expr) → value
```

**説明:**
与えられた式を評価せずにそのまま返します。コードをデータとして扱うのに使用します。

**例:**
```scheme
(quote (+ 1 2))     ; => (+ 1 2)  [評価されない]
(quote hello)       ; => hello
(quote (1 2 3))     ; => (1 2 3)
(quote ())          ; => ()
```

**ショートカット記法:**
```scheme
'(+ 1 2)            ; (quote (+ 1 2)) と同じ
'hello              ; (quote hello) と同じ
'(1 2 3)            ; (quote (1 2 3)) と同じ
```

**比較:**
```scheme
(+ 1 2)             ; => 3     [評価される]
'(+ 1 2)            ; => (+ 1 2) [評価されない]
```

### `(list elem1 elem2 ...)`

与えられた要素からリストを構築します。各要素は評価されます。

**シグネチャ:**
```scheme
(list [elem1 elem2 ...]) → list
```

**説明:**
引数を評価して、その結果をリストの要素にします。引数がない場合は空リストを返します。

**例:**
```scheme
(list 1 2 3)        ; => (1 2 3)
(list)              ; => ()
(list 'a 'b 'c)     ; => (a b c)
(list (+ 1 1) (+ 2 1))  ; => (2 3)  [評価される]
```

**比較:**
```scheme
'(1 2 3)            ; => (1 2 3)  [クォート]
(list 1 2 3)        ; => (1 2 3)  [構築]
```

## 今後実装予定の手続き

### 比較演算

```scheme
(> num1 num2)       ; 大なり
(< num1 num2)       ; 小なり
(= num1 num2)       ; 等しい
(>= num1 num2)      ; 大なり等しい
(<= num1 num2)      ; 小なり等しい
```

### リスト操作

```scheme
(car lst)           ; リストの先頭要素
(cdr lst)           ; リストの残り
(cons elem lst)     ; 要素をリストの先頭に追加
(append lst1 lst2)  ; リストを結合
(length lst)        ; リストの要素数
(map func lst)      ; リストの各要素に関数を適用
```

### 制御構造

```scheme
(if condition then-expr else-expr)
(cond (test1 expr1) (test2 expr2) ...)
(case expr (key1 expr1) (key2 expr2) ...)
```

### 変数・関数定義

```scheme
(define name value)
(lambda (args) body)
(let ((var1 val1) (var2 val2)) body)
```

### 型チェック（述語）

```scheme
(number? expr)
(string? expr)
(symbol? expr)
(boolean? expr)
(list? expr)
(integer? expr)
```

## エラーハンドリング

組み込み手続きでエラーが発生すると、エラーメッセージが返されます。

### 一般的なエラー

| エラー | 原因 | 例 |
|--------|------|-----|
| `expects numbers` | 非数値引数を渡した | `(+ 1 "2")` |
| `expects at least N arguments` | 引数が不足 | `(/)` |
| `expects non-zero numbers` | ゼロを渡した（除算時） | `(/ 1 0)` |
| `Unknown operator` | 未定義の手続き | `(foo 1 2)` |

### エラー対応

エラーが発生した場合：

1. エラーメッセージを確認
2. 入力のデータ型が正しいか確認
3. 手続きのシグネチャを確認
4. 修正して再実行

```scheme
; エラー
(+ 1 "2")           ; エラー: + expects numbers

; 修正
(+ 1 2)             ; => 3  [OK]
```

## パフォーマンス

Scheme インタプリタは教育目的に設計されています。大規模な計算には以下の特性を念頭に置いてください：

- **浮動小数点演算**: 内部で f64 を使用
- **再帰の深さ**: 深いネストは遅い可能性
- **メモリ**: 大規模なリストの操作に注意
