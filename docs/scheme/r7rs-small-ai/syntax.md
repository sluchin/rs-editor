# 2. 構文

Scheme の構文は非常にシンプルです。ほぼすべてが S式（S-expression）で統一的に表現されます。

## S式（S-expression）

S式は「シンボリック式」の略で、Scheme の基本的な構文単位です。

### リスト記法

リストはカッコ `(` と `)` で囲まれた要素の列です：

```scheme
(+ 1 2)           ; 関数呼び出し
(quote (1 2 3))   ; クォート付きリスト
(1 2 3)           ; データとしてのリスト
()                ; 空リスト（nil）
```

### 原子値（Atom）

リストを構成する基本的な値：

#### 数値

整数と浮動小数点数をサポートしています。

```scheme
42              ; 整数
3.14            ; 浮動小数点数
-10             ; 負の数
0               ; ゼロ
1.5e-3          ; 科学記法
```

#### 文字列

ダブルクォートで囲まれたテキスト：

```scheme
"hello"         ; 単語
"Hello, World!" ; スペースを含む文字列
""              ; 空文字列
```

#### シンボル

クォートなしの識別子。変数名や関数名として使用されます：

```scheme
hello           ; シンボル
+               ; 関数名（もシンボル）
x               ; 変数名
map             ; 予約語ではない関数名
```

#### ブール値

真偽値を表します：

```scheme
#t              ; true（真）
#f              ; false（偽）
```

## クォート

クォート（`quote`）はある式を評価させず、そのままの形で返します。

### `quote` 形式

```scheme
(quote (+ 1 2))     ; => (+ 1 2)  [評価されない]
(quote hello)       ; => hello
(quote ())          ; => ()
```

### ショートカット記法

`'` を使うとコードが短くなります：

```scheme
'(+ 1 2)        ; (quote (+ 1 2)) と同じ
'hello          ; (quote hello) と同じ
'(1 2 3)        ; (quote (1 2 3)) と同じ
```

クォートがなければ `(+ 1 2)` は関数呼び出しとして **評価** されて `3` になりますが、
`'(+ 1 2)` はリスト `(+ 1 2)` そのものが返されます。

## コメント

Scheme では `;` からその行の終わりまでがコメントになります。

```scheme
(+ 1 2)         ; これは加算
; 次の行全体がコメント
; (+ 10 20)  [評価されない]

(* 3 4)         ; => 12
```

## 関数呼び出し

Scheme の関数呼び出しはプレフィックス記法（関数が最初）で記述します：

```scheme
(+ 1 2)         ; 加算
(- 10 5)        ; 減算
(* 3 4)         ; 乗算
(/ 20 4)        ; 除算
(list 1 2 3)    ; リスト作成
```

### 演算子の位置

従来の数学記法と異なり、演算子は最初に来ます：

```scheme
; Scheme の記法
(+ 1 2)         ; 1 + 2

; 従来の記法（Scheme では使えません）
1 + 2
```

## ネストされた式

複雑な計算はネストされた式で表現します：

```scheme
(+ (* 2 3) (- 10 4))    ; (2 * 3) + (10 - 4) = 6 + 6 = 12
(* (+ 1 2) (+ 3 4))     ; (1 + 2) * (3 + 4) = 3 * 7 = 21
```

評価は内側のカッコから外側へ進みます。

## 予約語と特殊形式

以下は Scheme の予約語です。これらはシンボルとして使用できません：

- `quote` - 式をそのまま返す
- `lambda` - 関数定義（実装予定）
- `if` - 条件分岐（実装予定）
- `define` - 変数定義（実装予定）

## スペースと改行

スペース、タブ、改行は構文的には区別されません。可読性のため自由に使用できます：

```scheme
; すべて同じ意味
(+ 1 2)
(+
  1
  2)
(+ 1 2)     ; コメントを挿入
```

## 構文エラー

一般的な構文エラー：

### 括弧のミスマッチ

```scheme
(+ 1 2         ; エラー: 閉じ括弧がない
(+ 1 2))       ; エラー: 開き括弧が多い
```

### クォートなしのシンボル評価

```scheme
hello          ; エラー: undefined variable
; クォートが必要: (quote hello) または 'hello
```
