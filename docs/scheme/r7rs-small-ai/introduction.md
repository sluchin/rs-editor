# 1. はじめに

## Scheme について

Scheme は Lisp ファミリーのプログラミング言語です。最小限の構文と強力な計算能力を備えており、教育目的から実用的なアプリケーション開発まで幅広く使用されています。

### Scheme の特徴

- **シンプルな構文**: コード全体がデータ構造（S式）として統一的に表現されます
- **関数型プログラミング**: 関数を第一級オブジェクトとして扱います
- **動的型付け**: 実行時に型が決定されます
- **ガベージコレクション**: メモリ管理が自動で行われます

## rs-editor の Scheme インタプリタ

rs-editor に組み込まれた Scheme インタプリタは、基本的な Scheme の機能を提供します。

### 主な機能

- **算術演算**: +, -, *, /
- **リスト操作**: quote, list
- **REPL**: 対話的な評価が可能

### 制限事項

現在の実装では以下の機能は未実装です：

- 変数定義（define）
- 条件分岐（if, cond）
- ラムダ式（lambda）
- 副作用操作（set!, display）
- モジュールシステム

これらの機能は将来のリリースで実装予定です。

## 基本的な概念

### S式（S-expression）

Scheme はすべてをリスト形式（S式）で表現します。

```scheme
(+ 1 2)          ; 関数呼び出し
(quote hello)    ; クォート
(1 2 3)          ; データとしてのリスト
```

### 評価モデル

Scheme では式を以下の規則で評価します：

1. **原子値**: 数値、文字列、シンボルは自分自身に評価される
   ```scheme
   42      ; => 42
   "hello" ; => "hello"
   ```

2. **リスト**: リストの最初の要素（演算子）を関数として、残りを引数として評価
   ```scheme
   (+ 1 2 3)  ; => 6
   ```

3. **クォート**: `quote` または `'` で始まる式は評価されずに返される
   ```scheme
   (quote (+ 1 2))  ; => (+ 1 2)
   '(+ 1 2)         ; => (+ 1 2)
   ```

## REPL での実行

rs-editor では REPL（Read-Eval-Print Loop）で Scheme コードを対話的に実行できます。

### 使用方法

1. rs-editor を起動
2. エディタにコードを入力
3. 評価したいコードをハイライト
4. `C-x C-e` で評価（実装予定）
5. 結果がミニバッファに表示

### 例

```scheme
; 計算
(+ 1 2 3)
; 出力: 6

; リスト操作
(list 1 2 3)
; 出力: (1 2 3)

; ネストされた式
(+ (* 2 3) (- 10 4))
; 出力: 12
```

## エラーハンドリング

Scheme インタプリタはエラーが発生すると、エラーメッセージを表示します。

```scheme
(+ 1 "hello")
; エラー: + expects numbers

(/ 1 0)
; エラー: / expects non-zero numbers
```

エラーメッセージを確認して、入力を修正し再度実行してください。
