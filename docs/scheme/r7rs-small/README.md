# Revised<sup>7</sup> Report on the Algorithmic Language Scheme（日本語訳）

アルゴリズム言語 Scheme 報告書 七訂版（R7RS small）の日本語訳です。
`../r7rs-small-spec-ja`（TeX ソース）から pandoc と前処理スクリプトで機械変換したもので、元の文書とは次の点が異なります。

- 索引（ページ番号ベース）は含まれません。
- 節番号の参照は変換時に計算した番号に置き換えています。
- 表示的意味論（形式的意味論）の数式は、変換できない部分を LaTeX のまま `latex` コードブロックで残しています。
- Scheme 例のタブ揃え（`⟹` の位置）は厳密には再現されません。
